# Каракули — социальная сеть с нарисованным от руки интерфейсом

Классическая соцсеть в духе ВКонтакте 2010–2015: страницы, друзья, лента, фотографии, сообщения, сообщества.
Чистые HTML5 / CSS3 / JavaScript (ES6+) без фреймворков. Данные хранятся в **LocalStorage** браузера.

**Сайт стартует пустым:** нет готовых пользователей, записей, фотографий и сообществ. Всё наполняется самими людьми после регистрации.

## 1. Запуск
```bash
cd karakuli
python3 -m http.server 8080      # или: npx serve .
```
Откройте http://localhost:8080/login.html. Для входа через Google нужен именно адрес http(s), с файла `file://` он не работает.
Остальное (регистрация по почте, страницы) работает и при открытии `login.html` двойным щелчком.

Удалить все данные в браузере: **Настройки → Внешний вид → «Удалить все данные в этом браузере»**.

## 2. Вход и регистрация через сервисы (Google, VK, Яндекс, Apple)
Настройки лежат в `js/config.js`.

* **Google (работает по-настоящему):** в console.cloud.google.com → «Учётные данные» → «Создать» → «Идентификатор клиента OAuth» (веб-приложение). В «Разрешённые источники JavaScript» добавьте адрес сайта (`https://ваш-сайт`, `http://localhost:8080`). Скопируйте Client ID в `googleClientId`. Вместо демо-кнопки появится официальная кнопка Google.
* **VK, Яндекс, Apple:** пока работают как демо: открывается форма «имя + почта», как будто их передал сервис. Настоящий вход через эти сервисы требует сервера (секретный ключ нельзя хранить в браузере). Точка подключения: `Karakuli.socialLogin({provider, providerId, email, first, last, avatar})` в `js/auth.js`.
* Без ключа Google кнопка тоже работает в демо-режиме.

Важно: в этой версии данные Google читаются прямо в браузере и не проверяются сервером. На настоящем backend токен нужно проверять на сервере (библиотека `google-auth-library`).

## 3. Публикация в интернете (это статический сайт)
* **GitHub Pages:** загрузите файлы в репозиторий → `Settings → Pages → main / root`.
* **Netlify:** app.netlify.com/drop, перетащите папку `karakuli`.
* **Cloudflare Pages / Vercel:** подключите репозиторий, команда сборки пустая.
* **Свой хостинг:** загрузите папку по FTP.

Для входа через Google добавьте адрес опубликованного сайта в «Разрешённые источники JavaScript».
В этой версии данные каждого посетителя лежат **только в его браузере**: люди не видят друг друга. Для настоящей сети нужен backend (раздел 5).

## 4. Реализовано
* Регистрация и вход по почте, вход через Google/VK/Яндекс/Apple, восстановление пароля.
* Лента и «Новости»: записи с фото, лайки, комментарии, репосты, закладки, фильтры, сортировка.
* Профиль: обложка, аватар, статус, онлайн, счётчики, вкладки, редактирование; чужие профили.
* Друзья: список, онлайн, заявки (входящие/исходящие), поиск, удаление.
* Сообщения: диалоги, непрочитанные, история, фото.
* Сообщества: каталог, создание, подписка, страница со стеной, редактирование создателем.
* Фотографии: альбомы, загрузка, удаление, просмотр, лайки и комментарии.
* Закладки: записи, фото, ссылки. Уведомления с отметкой прочитанных.
* Настройки: основные, аккаунт, приватность, уведомления, безопасность, внешний вид (светлая/тёмная тема, 3 цвета).
* Адаптивность: компьютер, планшет, телефон (нижняя навигация).
* Нарисованный стиль: рукописный шрифт (Caveat, грузится с Google Fonts), SVG-фильтры дрожащей линии, чернильные аватары, рисованные иконки.
Намеренно нет: музыки, видео, игр, историй, клипов, эфиров, магазина, донатов, NFT.

## 5. Что требует backend и базы данных
| Функция | Что нужно |
|---|---|
| Общие данные для всех | PostgreSQL: users, posts, comments, likes, friendships, messages, communities, photos, notifications |
| Безопасная авторизация | bcrypt/argon2, сессии/JWT, HTTPS |
| Проверка входа через сервисы | Проверка токенов на сервере; VK ID, Яндекс ID, Sign in with Apple (нужен секретный ключ) |
| Сообщения в реальном времени | WebSocket |
| Фото | Хранилище S3, сжатие, CDN (сейчас base64 в LocalStorage, лимит около 5 МБ) |
| Восстановление пароля, уведомления вне сайта | SMTP, push |
| Права и приватность | Проверка на сервере |
| Модерация, защита от спама | Серверная логика, лимиты запросов |
